# 自播日报控制台前端

这是自播日报控制台的纯静态前端源码，可作为一个独立 GitHub 仓库发布或备份。

## 本地运行

前端需要配套本地后端，启动上级目录的控制台后访问：

```text
http://127.0.0.1:8877
```

## GitHub 发布边界

这里只包含 `index.html`、`app.js`、`styles.css` 等静态页面文件，适合提交 GitHub。

严禁把上级目录的 `backend/`、`data/`、`logs/`、各平台采集目录、浏览器配置目录、会话文件或业务 CSV 一起提交。它们可能含登录态、访问令牌或业务数据。

GitHub Pages 无法直接连接到本机的 `127.0.0.1` API，因此适合作为界面源码展示；生产控制台仍应只在本机通过 `http://127.0.0.1:8877` 访问。
